## ADDED Requirements

### Requirement: 分析儀表板必須提供競賽排行入口
系統 MUST 在既有分析儀表板的報表切換區加入「競賽排行」入口，並沿用同一批已分析完成的結果資料。

#### Scenario: 使用者可在三種報表間切換
- **WHEN** 使用者已取得分析結果
- **THEN** 系統 MUST 允許使用者在總覽分析、區間比較與競賽排行之間切換

#### Scenario: 競賽排行沿用相同分析條件
- **WHEN** 使用者切換到競賽排行視圖
- **THEN** 系統 MUST 使用與目前分析結果相同的試算表、日期區間與 PTA 閾值，不得另外要求重新載入資料

### Requirement: 新增競賽排行時不得破壞既有報表功能
系統 MUST 在加入競賽排行後，維持既有總覽分析與區間比較的可用性與既有資料計算行為。

#### Scenario: 總覽分析仍可正常顯示
- **WHEN** 使用者完成分析並切換至總覽分析
- **THEN** 系統 MUST 照常顯示既有 KPI 與圖表，且不因競賽排行的加入而缺少資料或發生錯誤

#### Scenario: 區間比較仍可正常顯示
- **WHEN** 使用者完成分析並切換至區間比較
- **THEN** 系統 MUST 照常顯示既有比較資料與圖表，且不因競賽排行的加入而缺少資料或發生錯誤
