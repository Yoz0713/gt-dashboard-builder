## ADDED Requirements

### Requirement: 分析儀表板必須提供診所資料回訪分析入口
系統 MUST 在既有分析儀表板的報表切換區新增「診所資料回訪分析」入口，與總覽分析、區間比較、競賽排行並列。該視圖 MUST 沿用目前主試算表的分析結果，MUST NOT 引入獨立的試算表選取範圍，也 MUST NOT 改變其他三個報表的資料來源與計算結果。

#### Scenario: 使用者可在四種報表間切換
- **WHEN** 使用者已取得主試算表分析結果
- **THEN** 系統 MUST 允許使用者在總覽分析、區間比較、競賽排行與診所資料回訪分析之間切換

#### Scenario: 切換至診所資料回訪分析後其他報表不受影響
- **WHEN** 使用者查看診所資料回訪分析後再切回總覽分析、區間比較或競賽排行
- **THEN** 系統 MUST 照常顯示各報表原本的 KPI、圖表與數字，且不因新增報表而缺少資料或發生錯誤

#### Scenario: 尚未產生分析結果時不顯示報表切換區
- **WHEN** 使用者尚未成功取得主試算表的分析結果
- **THEN** 系統 MUST NOT 顯示包含診所資料回訪分析在內的任何報表切換入口

### Requirement: 診所資料回訪分析必須沿用主畫面的分析區間與 PTA 閾值
系統 MUST 將主畫面目前選定的分析區間套用為診所資料回訪分析的資料範圍，並將主畫面設定的 PTA 閾值作為聽損個案的判定依據。診所資料回訪分析 MUST NOT 提供自己的區間或閾值控制項。

#### Scenario: 變更分析區間後重新套用到診所回訪報告
- **WHEN** 使用者調整分析起迄年月並重新產生分析結果後查看診所資料回訪分析
- **THEN** 系統 MUST 依新的日期區間重新列出診所清單與各診所的統計數字

#### Scenario: 變更 PTA 閾值後更新聽損個案分類
- **WHEN** 使用者調整 PTA 閾值並重新產生分析結果後查看診所資料回訪分析
- **THEN** 系統 MUST 依新的 PTA 閾值重新計算各診所的聽損個案數與聽損比例
