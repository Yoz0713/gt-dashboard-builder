## Why

轉介診所是各聽力中心的重要客源，但目前儀表板對診所的呈現只有總覽分析裡的一張「熱門轉介診所 (Top 8)」長條圖。這張圖只回答「哪幾家診所轉介最多」，無法回答「這家診所轉介的病人後來怎麼了」。

實際的業務場景是：業務人員要帶著一份紙本或 PDF 報告回訪診所、當面向醫生說明「你轉介給我們的病人，我們做了什麼、成效如何」。目前沒有任何畫面能產出這種以單一診所為主體、可直接列印帶走的成效報告，也沒有地方能一次看到分析區間內出現過的所有診所名稱。

## What Changes

- 新增獨立的「診所資料回訪分析」報表視圖，與總覽分析、區間比較、競賽排行並列為第四個切換入口。
- 以來客紀錄中「診所名稱」欄位為分組鍵，列出分析區間內所有出現過的診所，並提供搜尋與排序（轉介人次 / 最近轉介 / 成交率）。
- 選定單一診所後產生該診所專屬的回訪報告，內容包含 KPI 摘要、自動產生的回訪重點、月度轉介趨勢、聽損程度與年齡分布，以及轉介客戶明細表。
- 報告可透過既有的瀏覽器列印機制匯出成 PDF，並提供專用列印版面（列印時隱藏選取面板、補上含診所名稱與分析區間的報告抬頭、明細表跨頁時重複表頭且不切斷單列）。
- 新增獨立的「轉介費用」區塊：列出各已配戴個案的成交金額，並依可調整的回饋比例（預設為成交金額的 10%）計算應回饋給該診所的轉介費用與合計。
- 客戶明細表加上成交金額與轉介費用欄位，並提供姓名遮罩切換，讓報告可依場合決定是否顯示完整姓名。
- 修正列印時圖表被頁面邊界裁切的問題。
- 診所名稱欄位改以模糊比對定位，並過濾 `#N/A`、`#REF!` 等無效值。
- 診所資料回訪分析沿用主畫面既有的分析區間與 PTA 閾值，資料來源維持目前主試算表，不引入多試算表複選。
- 補上分析層與 UI 層測試，涵蓋新報表與既有三個報表的回歸風險。

## Capabilities

### New Capabilities
- `clinic-followup-report`: 以診所名稱為主體的回訪成效報告，提供診所清單、單一診所的統計與明細，並支援列印匯出。

### Modified Capabilities
- `analysis-dashboard`: 儀表板報表切換區新增「診所資料回訪分析」入口，且必須維持總覽分析、區間比較與競賽排行的既有行為。
